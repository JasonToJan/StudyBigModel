## 本模块的三个"主线问题"

每天学习时，带着这三个问题对照当天的内容：

1. **这个机制解释了哪个工程现象？**（贵/慢/幻觉/失忆/复读……）
2. **它决定了我做应用时的哪个决策？**（选型/参数/架构/成本）
3. **01 模块的哪个概念在这里被"打开"了？**（把新原理锚到旧知识上）
