# 01. 对齐总览：从"会说话"到"会办事"

> Day4 学习笔记 · 第一篇 ｜ 阅读时间约 12 分钟
> 目标：读完这篇，你能解释基座模型为什么不能直接当产品、对齐到底在补什么，以及"两步走"框架的全貌。

---

## 一、先回到那个尴尬的现场

Day1 说过：预训练的产物是**基座模型（Base Model）**——读完了整座图书馆的怪才。

现在请这个怪才上岗。你问它："**北京有什么好吃的？**"

它大概率不会回答你，而是——

> 续写出："上海有什么好玩的？广州有什么特产？成都有什么……"

它的本能是**接话**，不是**回答**。训练时它见过太多"论坛提问帖"，所以最像的训练分布是"继续列问题"，而不是"好好答题"。

直接把基座当产品用，你会得到一个：

- 问东答西（续写而不是回答）
- 没有身份（你问"你是谁"，它可能反问你或续写新闻）
- 不懂礼貌（不会拒绝，也不懂格式）

**知识满分，情商为零，且不按常理出牌。** 这就是"对齐"要解决的问题。

---

## 二、对齐（Alignment）：让模型的言行符合人类意图

**定义**：让模型的输出行为，符合人类期望的方式——该回答时回答、该拒绝时拒绝、格式得体、态度可靠。

> 🔑 一句话：**预训练教会它"怎么说话"，对齐教会它"怎么办事"。**

一个直观的参照物：**客服新员工培训**。

- 预训练 = 招进来一个满腹经纶的高材生，什么都知道，但完全不懂"怎么面对客户"
- 对齐 = 入职培训：话术规范（SFT）、主管带教反馈（RLHF）
- 推理部署 = 正式上岗，通过 API 对外服务

而"入职培训"具体分两步走，这是今天的主线：

---

## 三、两步走框架：SFT 教格式 → RLHF 教偏好

### 第 1 步：SFT（Supervised Fine-Tuning，监督微调）—— 教"回答长什么样"

给模型看**成千上万条人工写好的标准问答范例**：

```
指令：北京有什么好吃的？
回答：北京美食融合了宫廷菜与市井小吃，推荐三类：
      1. 烤鸭——全聚德、大董……
      2. 涮羊肉——铜锅清汤……

指令：帮我把这段话翻译成英文
回答：好的，翻译如下：……
```

模型的目标只有一个：**学会"看到问题 → 给出这种格式的回答"这个模式**。它不是在背答案（范例里没有覆盖所有问题），而是在学**"回答问题"这个行为本身长什么样**。

类比：不是教高材生每一道题的答案，而是给他几万份**满分客服话术范文**——他看完自然知道，面对客户该用什么姿态、什么格式说话。

**这步的产出：会听话了，但只是"照猫画虎"级别的听话**——它知道该回答了，却未必知道哪种回答**更好**。

### 第 2 步：RLHF / DPO —— 教"哪种回答更好"

SFT 的天花板很明显：范文只能示范"合格"，教不了"品味"。

比如同一个问题，模型给了两个回答——都挺通顺，但一个啰嗦跑偏，一个简洁到位。这种**细微优劣**很难写成范文，但人类一眼就能分辨。

于是换思路：**不写范文了，让人类当裁判。**

- 让模型对同一问题生成多个版本的回答
- 人类只做一件事：**排序/打分**（哪个更好）
- 用海量这样的偏好数据，训练模型"朝着人类喜欢的方向"调整自己

类比：主管不再给范文，而是说"这两份方案，我看上 A 了，B 驳回"——员工被驳多了，慢慢就**悟**出老板的品味。学的是偏好，不是套路。

（RLHF 的具体机制——奖励模型、强化学习——以及开源社区更流行的简化版 DPO，下一课展开。）

## 四、工程视角：对齐和你未来工作的三个交集

作为应用工程师，你不参与训练，但**对齐决定了你每天面对的是什么样的模型**：

### 1. 你调用的 API = 已经对齐完毕的模型

从今天起要建立这个区分意识：**你调的从来不是"最原始的模型"，而是"被 SFT+RLHF 调教过的对话模型"**。它的听话、格式感、礼貌，都是对齐的产物。

### 2. 拒答行为是对齐给的，不是模型"有立场"

"我无法协助这个请求"——这句话不是模型想说的，是对齐训练**教它说的**。工程上你会经常和它打交道：合法请求被误伤（安全策略过紧）时，你要靠改写 prompt 绕开误判，这叫与"安全税"共处。

### 3. Step10 微调的起点意识

未来学微调时（Step10），你要亲手做的小规模 SFT 就是今天讲的第 1 步——只不过数据是你自己构建的（Step11 训练数据构建）。**今天建立的概念，是 4 个月后微调课的地基。**

---

## 五、本篇小结

1. 基座模型只会**续写**不会**回答**——知识满分、情商为零，不能直接当产品
2. **对齐** = 让模型行为符合人类意图；类比高材生的入职培训
3. 两步走：**SFT 教格式**（看几万份满分范文，学"回答长什么样"）→ **RLHF/DPO 教偏好**（人类当裁判排序，学"哪种更好"）
4. 你调用的 API = 对齐完毕的对话模型；拒答与"安全税"是对齐的产物
