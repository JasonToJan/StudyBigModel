# 04. 开源模型分类与选型：三看定终身

> Day4 学习笔记 · 第四篇（收官）｜ 阅读时间约 12 分钟
> 目标：读完这篇，你能用"三看"法给任意开源模型建立档案，并说出 Qwen / GLM / DeepSeek 三大谱系的定位差异。

---

## 一、先说结论：选模型就看三件事

开源模型动辄几百个，型号名看得人眼花。但选型其实只看三件事：

> 🔑 **第一看型号（它是什么角色）→ 第二看规模（多大）→ 第三看 License（能不能商用）。**

类比招聘一个人：先看岗位性质（是做客服还是做编码），再看资历深浅，最后看合同条款能不能签。三步走完，选型就定了。

---

## 二、第一看：型号——它是什么角色

型号后缀就是"岗位说明书"，回顾 Day1 和今天的知识就能读懂：

| 后缀 | 角色 | 出处 |
|---|---|---|
| 无后缀（如 Qwen2.5-72B） | **基座**：只会续写（Day4 第 1 课） | 预训练产物 |
| **-Chat / -Instruct / -it** | **对话模型**：对齐完毕，日常首选（三者同义，各家叫法不同） | SFT + RLHF/DPO |
| **-Coder** | 代码专精版 | 领域强化训练 |
| **-VL**（Vision-Language） | 能看图的多模态版 | 多模态扩展 |
| **-Math** | 数学推理专精 | 领域强化 |
| embedding 系列（bge、gte、Qwen-Embedding） | **只转向量不生成**——检索专用（Day2 三大架构里的 Encoder-only） | RAG 的检索半边 |

实例读法：

- `Qwen2.5-72B-Instruct` = 720 亿参数、对齐完毕的对话模型
- `Qwen2.5-Coder-32B-Instruct` = 代码专精、320 亿、对话版
- `bge-m3` = 语义检索专用向量模型（没有 -Chat，因为它压根不生成文字）

> 🔧 读取口诀：**先看角色后缀，再看数字规模。** 选型第一问永远是"我要它干什么活"——对话找 Chat，检索找 embedding，写代码找 Coder。

---

## 三、第二看：规模——多大才合适

参数量是"脑容量"，也直接决定**部署成本**。主流档位速查：

| 档位 | 典型用途 | 部署门槛 |
|---|---|---|
| 0.5B ~ 3B | 手机端侧、输入联想、简单分类 | 单卡甚至 CPU 可跑 |
| 7B ~ 14B | 中小项目主力、微调练手 | 一张消费级显卡（常需量化） |
| 32B ~ 72B | 高质量生产场景 | 多卡 / 专业级显卡 |
| 100B+ | 旗舰，追逐极限能力 | 基本只通过 API 使用 |

规律与取舍：

- 参数越大能力越强，但部署成本**陡峭上升**——选型的本质是"**够用就好**"
- 很多任务 7B~14B 就绰绰有余，盲目上大模型 = 白烧钱
- **我们学习阶段主要走 API**：平台帮你部署和维护，按 token 付费。自部署（vLLM、量化等）是后期课程的专题，现在建立档位意识即可

---

## 四、第三看：License——能不能商用

**最容易翻车的坑**：开源 ≠ 免费随便商用。

| License 类型 | 例子 | 商用规则 |
|---|---|---|
| Apache 2.0 / MIT | Qwen 多数系列 | 几乎无限制，放心商用 |
| 自定义社区许可 | Llama 系（月活 7 亿以上需授权）、部分 GLM 版本 | 一般项目可用，超大规模需谈授权 |

类比：像"图片网站标着免费下载，但角落写着商用需授权"——**用之前一定去 Model Card 的 License 区确认一眼**，这是三看里花时间最少、但翻车代价最大的一看。

---

## 五、三大谱系速览：Qwen / GLM / DeepSeek

我们的技术栈主用国产模型，三家定位各有侧重：

| 谱系 | 出品 | 定位特点 | 典型使用 |
|---|---|---|---|
| **Qwen（通义千问）** | 阿里 | **型号最全**（0.5B 到千亿级，Chat/Coder/VL/Embedding 全家桶），Apache 居多，开源生态最开放 | 选型万金油；微调练手首选小尺寸 Qwen |
| **GLM** | 智谱（清华系） | 对话与 **Agent 能力**见长，API 生态完善 | Agent 开发（08 模块）、通用对话 |
| **DeepSeek** | 深度求索 | **推理能力与极致性价比**著称（V3 / R1 系列，MoE 架构——知道名字即可） | 预算敏感的学习与实验；推理类任务 |

三家都提供低价 API，学习阶段任选其一即可，切换成本低（API 格式大同小异——04 模块你就能体会）。

## 六、我们的选型决策树（贯穿学习路线）

```
要什么活？
├─ 学习 / 实验 / 日常问答 → 大厂 API（DeepSeek / GLM / Qwen 任一，便宜省心）
├─ RAG 语义检索 → bge 系列 embedding 模型（Encoder-only，Day2 的老朋友）
├─ 微调练手（Step10）→ Qwen 1.5B~7B（小模型，消费级显卡跑得动）
├─ Agent 开发（08 模块）→ GLM / DeepSeek（工具调用与推理强）
└─ 生产上线 → 走完三看流程，License 最后确认
```

---

## 七、Day4 全篇总结（四篇串起来）

1. **01 对齐总览**：基座只会续写；对齐 = 入职培训，SFT 教格式 → RLHF 教偏好
2. **02 SFT/RLHF 细看**：SFT 学行为不学知识（质量>>数量）；RLHF 靠奖励模型这个"替身评委"；DPO 砍中间商
3. **03 副作用**：拒答会误伤、谄媚源于人类偏爱附和、对齐税压制续写——prompt 层都有应对
4. **04 本篇**：选型三看——**型号（角色）、规模（档位）、License（商用）**；三大谱系各有定位

> 至此"一个模型从出生到上线"的完整拼图完成：**预训练（学知识）→ 对齐（学听话）→ 部署选型（上岗）**。明天 Day5 收官 01 模块：全链路复盘 + 你的第一个 API Demo。
