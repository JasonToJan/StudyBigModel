## 二、学习内容（约 95 分钟）

### 1. 生成逻辑：概率分布 → 文字（20min）

- 输出层的原始分数（logits）→ softmax 归一化 → 概率分布
- 两种基本策略：**贪心解码**（永远挑第一名）vs **随机采样**（按概率掷骰子）
- 为什么纯贪心会呆板、纯采样会跑偏——引出"调节旋钮"的必要性

### 2. temperature（25min，今日重点）

- 原理直觉：温度是给整张概率表做"重新分配"——低温让赢家通吃，高温让众生平等
- 低温：稳定、保守、可复现倾向；高温：多样、有创意、也更容易翻车
- 类比：考试抄第一名（低温）vs 全班抽签（高温）

### 3. top_p / top_k（20min）

- 核采样：只从"累计概率达 p 的头部候选"里抽——先把烂选项踢出局，再谈随机
- top_k：只保留分数前 k 名
- 它们和 temperature 的分工与配合（先用 top_p 圈定候选人，再用 temperature 调抽签偏好）

### 4. 常用参数全家福（15min）

- max_tokens：输出上限（对应 Day1 讲过的"答到一半被掐断"，finish_reason=length）
- stop：自定义停止条件
- repetition_penalty / frequency_penalty / presence_penalty：治"复读机"
- seed / stream：复现与流式（Day1 已埋过伏笔）

### 5. 场景选参指南（15min）

| 场景 | 温度倾向 | 理由 |
|---|---|---|
| 客服问答、代码生成、数据提取 | 低温（0~0.3） | 稳定准确第一 |
| 创意写作、头脑风暴 | 较高（0.7~1.0） | 要多样性 |
| 结构化输出（JSON） | 低温 + 低 top_p | 格式不能错 |

## 三、实操任务（约 60 分钟）

### 实操 1：亲眼看参数拧动效果（25min）

- 用任一平台的调试页（智谱/DeepSeek/Qwen 均可），固定同一个 prompt（如"给奶茶店起个名字"）
- 分别用 temperature = 0 / 0.5 / 1.0 各生成 3 次，记录输出的稳定性与多样性差异
- 记录进 `param_test.md`

### 实操 2：治一治复读机（15min）

- 用 prompt 故意诱导重复（如"重复'好'这个字 50 次"或让它写重复句式）
- 观察 repetition_penalty / frequency_penalty 开关前后的差异

### 实操 3：给三个场景配参数（20min）

- 场景 A：电商客服自动回复；场景 B：写小说开头；场景 C：从合同里抽取关键信息输出 JSON
- 每个场景写出一套完整参数（temperature / top_p / max_tokens / 其他）+ 一句话理由
