## 二、学习内容（约 70 分钟）

### 1. 全链路复盘（40min）

一条流水线串起五天：

```
你的文字 → [Day1] 切 token → [Day2] Embedding 语义地图 + 位置座位号
        → [Day2] N 层 Block 全员开会（Q/K/V 注意力）
        → [Day2] 输出层打分 → 概率表
        → [Day3] 采样参数决定挑哪个 token
        → [Day1] 拼回输入，循环往复，直到闭嘴
        → [Day1] 逐 token 流式推给你的屏幕
        ↓ 以上成立的前提
        [Day4] 它是预训练+对齐调教出来的"听话助手"，且是你三看选型选来的
```

### 2. 极简 Demo 讲解（20min）

- API 调用四要素：**base_url、api_key、model、messages**
- messages 三种 role：system（人设/规则）、user（用户）、assistant（模型）
- 回包解剖：choices[0].message.content / usage / finish_reason
- 非流式 vs 流式：`stream=False/True`，一行之差（Day1 第三课的伏笔正式兑现）

### 3. 模块 01 收官（10min）

- 五天知识地图回顾
- 整个模块回答的三个大问题：模型是什么 / 它怎么工作 / 它怎么被调教
