## 一、三句话带走整个模块

**1. 模型是什么？**（Day1）
一个概率生成器，不是检索器。它预测下一个 token，所以有幻觉、有知识截止、算不准、无记忆——四大边界就是后续所有课程（prompt / RAG / 工具调用）的出发点。

**2. 它怎么工作？**（Day2~3）
token 进 → Embedding 上地图 → 注意力全员开会 → N 层加工 → 概率表出 → 参数遥控挑 token → 自回归循环 → 流式交付。一条流水线，全部成本按 token 算。

**3. 它怎么被调教出来的？**（Day4）
预训练学知识（产物=只会续写的基座）→ SFT 教格式（学行为不学知识）→ RLHF/DPO 教偏好（人类当裁判）→ 三看选型上岗。你调用的 API 是对齐完毕的模型，拒答和谄媚都是调教的副产品。

## 三、能力盘点：此刻你已经能做的事

- **读文档不晕**：API 参数表、模型命名（-Chat/-Coder/-VL/bge）、Model Card，都能对上概念
