## 二、学习内容（约 95 分钟）

### 1. 诞生背景：为什么需要 Transformer（20min）

- 2017 年论文《Attention is All You Need》——标题即宣言："只要注意力就够了"
- RNN 的两大痛点：**串行处理慢**（无法吃满 GPU）、**长距离遗忘**（传话游戏式信息衰减）
- Transformer 的解法：所有 token 两两直连（全员开会，不再逐个传话）

### 2. 整体架构鸟瞰（25min）

- 数据流向：文本 → Embedding（文字变向量）→ 位置编码 → N 层 Transformer Block → 输出层（预测下一个 token）
- 每个组件干什么：用"工厂流水线"类比建立整体印象
- Embedding 的直观理解：词变成几何空间中的"位置"，意思相近 = 距离相近

### 3. 三大架构分类（20min）

| 架构 | 擅长 | 代表 |
|---|---|---|
| Encoder-only | 理解（分类、检索、embedding 模型） | BERT |
| Encoder-Decoder | 输入输出都是序列（翻译、摘要） | T5 |
| Decoder-only | 生成（对话、写作、代码） | GPT / Qwen / GLM / DeepSeek |

- 重点理解：**为什么 LLM 主流是 Decoder-only**（生成任务 + 自回归天然契合 + 训练效率 + 规模化验证）

### 4. 自注意力直观理解（30min，今日重点）

- 核心动作：每个 token "环顾四周"，判断句中谁和自己有关，按相关度加权吸收信息
- 例："小猫追老鼠，**它**跑得很快"——"它"通过注意力锁定"老鼠"
- 只建立直觉，不推公式；Q/K/V 概念预热（明天 Day3 会从"生成逻辑"角度再回望）
